# Shape v0.9.0

Shape v0.9.0 publishes Swift source drafts in the released `shp` CLI so any
repository can generate conservative Shape from `.swift` files.

## Highlights

- Add Swift as a first-class `shp ast source` language. `.swift` files infer
  the Swift parser, and `--language swift` selects it explicitly.
- Bundle the Swift Tree-sitter parser beside the other supported parsers in
  every release archive. Swift drafts do not need a Swift compiler, Xcode, or
  SwiftPM target configuration.
- Project classes, structs, enums, actors, protocols, and extensions as type
  candidates. Functions, protocol requirements, initializers, deinitializers,
  subscripts, and computed properties, including SwiftUI `body`, become
  function candidates.
- Keep every Swift effect unknown and emit no inferred Swift calls or
  candidate effects. Nested types with a local function owner stay inside
  that function's evidence.
- Leave `shp analyze` unchanged: Swift AST support is not Swift effect
  analysis. Do not treat an empty analyzer result as evidence about
  SwiftData, Core Data, GRDB, or other Swift persistence libraries.

## Shape plugin

The coordinated `0.9.0` plugin documents Swift as current CLI behavior in
`shape-lang`. Generated Swift drafts remain navigation evidence until a human
reviews and promotes them into authored architecture claims.

## Release assurance

- Keep the six-skill static conformance and focused behavioral canaries as a
  blocking release-candidate gate.
- Keep the protected `skills-release-approval` environment as the human gate
  before coordinated CLI and plugin tags can be created.

## Distribution

The release publishes Linux x64, Linux ARM64, macOS ARM64, and Windows x64
archives, release-specific installer scripts, and SHA-256 checksums. The setup
action is verified against the published release on Linux and Windows.
