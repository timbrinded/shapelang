SHAPE 1.0 FORMAL ANNEX (version 7, release candidate)

Normative. A.n refines core model §n; A.12 the records and contract document; A.13 the syntax; A.14 the examples; A.15 fixes the readings the differential test found ambiguous. The annex governs detail; a difference in meaning from the core is a defect, and until the differential gate reports zero residual (A.11.2) this text, not either implementation, is the reference. Meanings are version 6's unless stated; every version 7 change, including those from the completeness review, is listed in the RFC (D1–D28) with its evidence. In the decision mapping, M§, S§, R§ and X denote the core model, syntax, records and examples documents, and A.x.y-z denotes A.x.y to A.x.z. [Dn] cites decision n of the RFC.

A.0 CONVENTIONS
A.0.1 MUST, MUST NOT, SHOULD, MAY are normative.
A.0.2 Sets finite, functions total and pure, outputs sorted by codepoint unless stated; core output (A.12.10) is byte-identical under any input order.
A.0.3 Q = module::Name; units module::Component.unit; pseudo-unit K.* = K's code no unit binds; ungoverned (reserved) = code no component owns. Verbs, edge kinds, hatch kinds share one namespace per shape (E-shadow), unqualified.
A.0.4 JCS = RFC 8785; H(x) = "sha256:" + hex(SHA-256(JCS(x))). No floats in hashed or core-output values; integers within ±(2^53 − 1).
A.0.5 Instants are integer UTC seconds; Dates are 00:00:00Z. now comes from the CI runner; the checker uses now* and reads no clock, environment, file or source.
A.0.6 Evidence ids: R1–R6, E1–E10 (Verus probes), Bend-A1…G8. checker, tooling abbreviate shape.checker, shape.tooling.
A.0.7 Question codes L0, L1, L3, L4, L6, L7; L3–L4 are one question (NoWeakerClaim) per claim family, codes kept for deltas and display. L2 (folded into L1 in version 7) and L5 are retired, not reused.

A.3 CODE, VOCABULARY AND BINDINGS
A.3.1 Shape files and packs
A.3.1.1 Shape files: shape.lock at the root plus every .shape file under shape/ outside shape/evidence/; the input must hold exactly these with matching blob ids (else invalid). Other .shape files are raw.
A.3.1.2 One shape declaration: owner of last resort, optional policy (default std::DefaultPolicy), optional manifest identity (A.5.2.17).
A.3.1.3 shape.lock pins (name, version, digest), digest = H({"v":"shape.pack.v1","files":[[path, hex(SHA-256(bytes))]…]}) by path. import std.
A.3.1.4 packs covers every pin of either lock; a bad head pin is invalid, a bad base pin a base defect.
A.3.1.5 Packs export effects, kinds, hatch kinds, Trust, templates and policies, never active claims; a shape declaration reusing a pack name is E-shadow.

A.3.2 Code identities and manifests
A.3.2.1 lang:path[#symbol] under <lang>.ids.v1 (A.12.2). Anonymous functions are not identities (facts go to the nearest enclosing one); same-name declarations in a file merge (merged: n).
A.3.2.2 Every tracked file except shape files and conforming record files is an identity; unclaimed files are raw:<path> (file, own = bytes).
A.3.2.3 Command code: pkgjson (one unit per package.json script), gha (one identity per workflow job, one unit per run step); executable shell. Other JSON, YAML, TOML are data.
A.3.2.4 Executable: registered languages; raw files on the script list, starting #!, or mode 100755; command code. The manifest states it per file identity (flag executable, A.12.7.5); the checker verifies the mode against the tree, while #! and the script list rest on the manifest identity (A.5.2.17). An executable raw or command identity is a raw carrier (A.12.4) [D27]. Shape: 70 raw executables of 387 raw files (rawexec4.py).
A.3.2.5 Projections: file; own (the identity's text with each nested identity replaced by its path-free symbol name, nothing resolved and no env(x), so code moved unchanged keeps its own digest; used for finest changes, relocation, coverage, bindings and markers) [D6]; unit (own plus env(x)); Verus contract, closure. R1 trigger rates: unit 89.0%, contract 65.6%, closure 68.0–75.8%, at trust 50.2% (E9). No exec or trust projection.
A.3.2.6 Manifest M: (identity, projection) → digest, plus kind, parent, refs (the identities env(x) resolves to, A.5.7.2), markers and the flags executable (A.3.2.4) and hatchComplete (A.3.4.4) [D27]; ids(M) excludes shape and record files. Built without executing head code and checked against the git tree and commit (A.12.7.5), hence complete; digests, refs, markers and flags, which the checker cannot recompute, are authenticated by the manifest identity (A.5.2.17).
A.3.3 Components, attribution, resources, calls
A.3.3.1 Component (owner, tier, paths, except paths, grants, units, complete kinds, was); grants none = empty; no grants = open authority. Boundaries add allows (hatch kinds) and assumes (id, text).
A.3.3.2 A unit binds one identity; default: the unique identity with the unit's name as last symbol segment within ⟦paths(K)⟧ (ids(M_h) without paths); none E-unbound, several E-ambiguous (head only).
A.3.3.3 Globs as globToRegex (packages/shp-checker/src/checker/globs.ts): **/ → (?:.*/)?; other ** → .*; * → [^/]*; ? → . ; else literal; anchored; no braces or negation inside a glob; compiled to DFAs. A component's except globs remove paths from all of its globs [D25].
A.3.3.4 Specificity: leading wildcard-free segments; literal paths count all.
A.3.3.5 att_S(x): the unit bound to x's nearest ancestor-or-self; else K.* for the most specific glob of K that matches x's path while no except glob of K does; else ungoverned (shape owner, tier normal). Code sets partition ids(M).
A.3.3.6 E-overlap (head): two units on one identity; equal-specificity globs of two components with intersecting languages (on automata); two resources binding one resource code. A unit inside another component's paths is legal.
A.3.3.7 Resources bind tag.kind("value"), dialect in the tag; the registry's canon (pure string function) normalises bindings and facts (A.12.4).
A.3.3.8 Resolution beyond strings is a provider duty under presence soundness (callees resolved, new C(…) calls C, tables schema-qualified); unknown means incomplete and heuristic.
A.3.3.9 res_S(t): the unique resource binding t; res_S(trust) = Trust; else t is unmapped (health; new facts raise vocabulary coverage). Claims about unbound resources constrain declared facts only (declared-only, A.4.5.6). A resource-code kind absent from the registry has no carriers (A.12.4): its channels apply to no code, so claims on it are declared-only and raise no coverage [D3]. Naming Trust or Undeclared in a grant, summary or binding is E-unknown.
A.3.3.10 Calls° = call facts with both ends in ids(M_h) (others counted as externalCalls) plus (bind(u), bind(v)) per a via v. Refs° = manifest refs with both ends in ids(M_h); refs are not calls and never induce edges. Unit-level calls only induce component edges.
A.3.4 Effects and hatches
A.3.4.1 Atom Verb<Resource>; ⇒ = reflexive-transitive implies, acyclic (E-effect-order); atoms imply only on the same resource; cl = up-closure, ↓ = down-set.
A.3.4.2 std: Export ⇒ Read; Append, Import, Update ⇒ Write; Redact, LogicalDelete, HardDelete ⇒ Update; Truncate ⇒ HardDelete; DropStorage ⇒ Truncate.
A.3.4.3 effect Hatch; effect Undeclared implies Hatch (std; reserved: no hatch line, allows, grant or summary may name it). hatch h in L declares h ⇒ Hatch for a registry hatch kind of L (E-unknown otherwise); hatch h1, h2 in L is sugar; one verb may be declared for several languages (std: unsafe in bend and rust). A hatch fact lifts to h<Trust>.
A.3.4.4 The manifest counts each hatch kind's markers in each identity's own text; n > 0 gives (x, h, n), sound for presence and absence at identities flagged hatchComplete: parsed, and every macro invoked in x, in item, statement, expression, attribute or derive position, is defined in the tree with no marker in its definition, is verus!, or is on the registry's builtin list (A.12.2.8); include! counts as in-tree code only with a string-literal path to an in-tree hatch-complete file, whose markers are then counted at x [D20]. No provider declares hatch channels.
A.3.4.5 Registry hatch kinds the shape does not declare lift to Undeclared<Trust> (never declared assumptions); undeclared verbs to isolated atoms with ↓v = {v} (not permitted by closed authority, not protected, raise vocabulary coverage); undeclared edge kinds are dropped and counted.
A.4 CLAIMS
A.4.1 Fields
A.4.1.1 id: Q (+ /<12 hex of fp> per clause), <bearer>/<Template>/<op>-<arg> or …/law, <K>/authority; display only; names claims in shape judge lines.
A.4.1.2 owner: explicit, else the subject's (a unit's component's), else the shape owner; owner github("alice") declares an implicit person; memberships live in the shape.
A.4.1.3 tier ∈ {low, normal, critical, final}: explicit, else the bearer's or subject component's, else normal; forbid final = tier final; final uses critical's policy plus fixed rules; std templates carry no tier; tier is outside the NF.
A.4.1.4 Requirement: laws only.
A.4.1.5 fp = H(NF), excluding owner, tier, requirement.
A.4.1.6 Polarity (upper forbids, lower asserts), family and decided-by are functions of op (law: of the statement form).
A.4.1.7 Equal fps merge: all ids, highest tier, strictest requirement, owner of the highest-tier id (ties: least id); obligations deduplicate.

A.4.2 Operators
A.4.2.1 Over the claim shape's lifted world: edge.exists(A,k,B) (lower) iff (A,k,B) ∈ E; n-node relations are consecutive pairs (std coordinated_call). path.forbid(S,T,K,V): no K-path s⇝t, s ∈ S∖V, t ∈ T, interior outside V. edge.forbid(S,X,k,T,Y): no (s,k,t), s ∈ S∖X, t ∈ T∖Y. cycle.forbid(K): E|K acyclic. authority(K), iff K declares grants: every non-trust atom of Xd(u), u ∈ U(K), in cl(G(K)). effect.forbid(a,Σ,X): Xd(u) ∩ ↓a = ∅ for u ∈ U(Σ)∖U(X), * = all units, pseudo-units and ungoverned. effects.upper(u,C): Xd(u) ⊆ cl(C), via entries ignored (u's own code only); effects.lower(u,C) (lower): each plain atom of C is in Xd(u), and each a via v asserts the call pair and a ∈ Xd(v); effects unknown: no claim. law(on, statement): uninterpreted; schema (template instance, providers deciding template Q), hosted (symbol at closure), informal (judgment).
A.4.2.2 UnitSel {*, ungoverned, component K, unit u}; NodeSel {*, component K, resource R}; ungoverned is never a node; wrong sort: E-unknown.
A.4.2.3 relations complete over K in A: per k, edge.forbid([A], [], k, [*], A's declared k-targets).
A.4.2.4 forbid hatch K outside boundaries (HatchesStayAtBoundaries<>: K = *): per declared hatch verb h ∈ ↓K, effect.forbid(h<Trust>, [*], [component B | B allows h]), plus, when K is * or Hatch, effect.forbid(Undeclared<Trust>, [*], []), with the clause's tier and owner. Hatch itself is never a clause [D1]. allows growth changes the NF and L1 sees lost protection; exceptions and notes on the rule cover every clause. forbid Hatch<Trust> within component K still forbids every hatch in K, Undeclared included.
A.4.2.5 Open authority (no grants clause) is health; removing the last grant loosens, adding the first tightens; ungoverned has no authority; grants, allows, assumes are fields compared by L1, L7.
A.4.2.6 std ReviewedSurface<B>: informal law judged at trust; removal is L4 law removed.
A.4.2.7 Op order: A.5.6.4.

A.4.3 Templates
A.4.3.1 Parameter kinds resource, component, unit, effect, kind, value (string or safe integer; float E-template), code.
A.4.3.2 Attachment X : N<rest> binds X first; marker templates have empty bodies (when T has N).
A.4.3.3 Named instances write all arguments; a law's on comes from unit, component or code parameters, else is written; laws on resources only: E-law-target.
A.4.3.4 Template laws without statement are schema laws: schema = template name, version schemaFp (order table included).
A.4.3.5 order P by leq|geq|subset|superset|equal (default equal) defines head-at-least-as-strict per parameter; part of the op order and schemaFp. leq and geq order safe integers only; a string argument at a parameter ordered leq or geq is E-template, since strings order only by equality [D13]. subset and superset order sets of references. std Bounded: Lo geq, Hi leq.
A.4.3.6 requires note K: a note of kind K about the bearer or instance (E-note-missing).
A.4.3.7 Expansion is substitution then elaboration; self-attachment, arity or kind errors: E-template.
A.4.3.8 Hosted statements loosen only via equal closure digests, implies records or answers.
A.4.3.9 Packs export templates, never instances; providers decide schema laws via decides template Q.

A.4.4 Worlds and evaluation
A.4.4.1 X° = ids(M_h) ∪ Cells. W° = (F° ⊆ X° × Verb × RC°, Calls° ⊆ X° × X°, Ed° raw non-call edges); RC° = canonical resource codes plus trust.
A.4.4.2 Lifting by S: Xd_S(u) = ⇒-closure of (att_S(x), lift_S(v,t)) for facts at x ∈ code_S(u) with res_S(t) defined, plus atoms W_decl declares for u, over units, pseudo-units and ungoverned (A.3.4.5 for undeclared vocabulary). E_S: declared-kind raw edges lifted by comp(att_S) and res_S, plus calls between distinct components; edges touching ungoverned dropped (ungovernedCalls counted). Version 6's transitive Xt is removed: summaries are direct [D2].
A.4.4.3 ⟦S⟧° = worlds satisfying every upper bound of S; both shapes lift the same W°.
A.4.4.4 W_decl(S): declared edges; (u,a) per plain summary entry; for a via v the call pair and (v,a) (target with a complete summary lacking a: E-conduct).
A.4.4.5 W_obs°: usable observation entries' facts and M_h hatch facts. Observed facts anchor to the entry of the nearest ancestor-or-self of at (unanchored: ignored, counted). at ∉ ids(M_h): relocated to the nearest ancestor by parentOf, subject relocated, fact id raw, heuristic. Paths absent from the tree: RJ12. n = max over sources. Presence-sound iff a manifest or a provider presence-sound under G* (a) reports it at its exact location; declared facts are presence-sound.
A.4.4.6 W_eval = W_decl(S_h) ∪ λ_{S_h}(W_obs°), closed under ⇒ and induced edges.
A.4.4.7 A(u) = cl(G(comp(u))) ∪ TrustAtoms if comp(u) declares grants, else all atoms; S(u) = cl(C) ∪ TrustAtoms if u has effects.upper(u,C), else all atoms; Prot(u) = ⋃ ↓a_f over effect forbids covering u; P(u) = (A(u) ∩ S(u)) ∖ Prot(u), up-closed. Lvl(u)(a) = the highest tier among forbids putting a in Prot(u), u's summary if a ∉ S(u), and authority(comp(u)) if a ∉ A(u); ⊥ if none. raw_fact_exact: all authority, summary and effect-forbid claims hold iff every raw fact (x,b) with att(x) = u has b ∈ P(u) (proved for forbids and authority; summaries intersect the same way). Excluding claims of b ∉ P(u): forbids putting b in Prot(u), the summary if b ∉ S(u), authority if b ∉ A(u); the obligation goes to the first by (tier*(o) descending, effect.forbid before summary before authority, fp), others in causes; no precedence, so exceptions must match all.
A.4.4.8 Keys and witnesses: authority, effect.forbid, effects.upper {code, atom} (relocated at, raw atom), one fact; edge.forbid {from, to}, one edge; path.forbid {from: s, to: t} for a minimal pair (s ∈ S∖V, t ∈ T, interior avoiding V ∪ S ∪ T), the path; cycle.forbid {nodes} of a non-trivial SCC of E|K, the canonical-least cycle through its least node (≤ |N|/2 keys). Refuted lower bounds: null, or {unit, atom} per missing atom.
A.4.4.9 Representative: least supporting fact by (presence-sound first, declared first, fact id); true sorts before false (Example 4's 1bb37b4784f7693a) [D22].
A.4.4.10 Canonical witness: least by (heuristic facts, observed facts, facts, representative id sequence), via Dijkstra then lexicographic BFS; declared-only witnesses first.
A.4.4.11 Supp(k) by forward and backward passes over walks: authority, effect forbids, summaries: facts at code with that atom; edge: facts supporting (s,k,t); path: facts of K-edges (a,b) with a reachable from s and t from b through interiors outside V ∪ S ∪ T; cycle: facts of K-edges in the SCC. Exact except for paths (over-approximate; only more conservative). Vector s→m→x→y→m→t: all five edges. Supports decide introduced, bindings, groups; witnesses are reported (A.15.4).
A.4.4.12 Coherence errors: violations within W_decl(S_h) (E-conduct, E-structure), one error per (claim fp, subject key). A subject violated in W_decl is not also raised as a contradiction, so an observed fact whose {code, atom} a summary or relation on that identity also declares is reported once, as the error (Example 1 Variant A).
A.4.4.13 Contradiction: canonical witness in W_eval holds an observed fact; sound iff all its observed facts are presence-sound.
A.4.4.14 Refutation: every footprint identity has a usable complete entry on an applicable channel from a provider absence-sound under (a), and the fact is absent; always sound.
A.4.4.15 Sat of a checker-decided claim: no open contradiction. Observations only contradict.

A.4.5 Footprints and channels
A.4.5.1 authority(K): code(K), effect(t) for all bound t. effect.forbid(a,Σ,X): code(U(Σ)∖U(X)), chan(a). effects.upper(u), effects.lower(u): code(u), effect(t) for bound t (no call channel) [D2]. edge.exists(A,k,B): code(A), prod(k,{B}). edge.forbid(S,X,k,T,Y): code(S∖X), prod(k,T∖Y). path.forbid, cycle.forbid: all governed code, prod(k,T) or prod(k,N) per k ∈ K.
A.4.5.2 chan(v<R>) = effect(t) per t bound to R; for Trust, hatch(L) per language with a hatch kind in ↓v. prod(k,T): call(L) for calls; edge(k) for kinds to components; edge(k,t) per bound t of T for kinds to resources (none if unbound). A claim with no channel is declared-only (A.4.5.6).
A.4.5.3 Applies to x: call(L), hatch(L) iff lang(x) = L; effect(t) iff lang(x) carries t's kind, or x is a raw or command identity flagged executable and t's kind lists raw carriers (A.12.4); edge channels iff x is executable. Raw data carries none; a kind absent from the registry is carried by nothing.
A.4.5.4 Laws have no footprint; their code is Req.
A.4.5.5 Lifting uses bindings only; summaries use their unit's own code; ungoverned is in * and never under authority.
A.4.5.6 Observability (need side): a channel t is observable iff a provider whose base declaration is absence-sound declares, in the base, a channel matching t (A.5.2.3), read from the base alone (G* (e)); hatch(L) channels always are (the manifest) [D3]. It decides coverage need (A.7.4.2), exploitation (A.8.3.1) and the declared-only listing; meeting a need uses (b) (A.7.4.3) and refutation uses (a) (A.4.4.14), so a head that drops absence keeps the need and cannot meet it. A claim with no observable channel is declared-only by construction: health lists it with its tier and route (contradiction-only if a base provider declares one of its channels, whatever its soundness, else declared-only), the CI summary counts them per tier, and teeth reports W_obs vacuity (A.10.5). This is how invariant 3's declared-only mark is computed for checker-decided claims (A.9.6).
A.4.6 Exceptions
A.4.6.1 One construct; no defer or due.
A.4.6.2 Target: a claim (all clauses) or component; kinds ⊆ {contradiction, unestablished}, default both; coverage not exceptable.
A.4.6.3 Σ: unit, component, ungoverned, code x, pair A -> B; resolved per identity under head bindings over M_h; only on checker-decided and component targets (else E-exception).
A.4.6.4 Attributed to K: {code, atom} with code ∈ code(K); {from, to} with from = K; {nodes} containing K; law obligations iff Req ≠ ∅ and Req ⊆ code(K) [D14].
A.4.6.5 Matched while now* < expires iff kind listed; claim is the target or attributed to the target component; with Σ: code ∈ ⟦Σ⟧, listed pair, ∅ ≠ Req ⊆ ⟦Σ⟧, {nodes} never. Several excluding claims: each matched. Exceptions match by code identity, so moving the excepted code drops the match and the exception becomes inert.
A.4.6.6 Matched non-introduced: owed debt. Matched introduced: owed debt once an exception answer lists it (eligible non-agents for owner* of each excluding claim), else unmatched severity. Witnesses stay visible; law exceptions are whole-claim.
A.4.6.7 Never on loosenings, coverage or tier*(o) final; E-exception iff the target claim's head tier is final, expiry beyond now* + 365 days, Σ on a law, or the target is unknown. A component target is never E-exception for holding final claims; it never matches their obligations (A.15.3).
A.4.6.8 Adding or widening an exception is no loosening question and not governance state.
A.4.6.9 Debt is flagged with ≤ 14 days left; expired exceptions are inert; an active exception that matched no obligation in the run is listed inert in health.
A.4.7 Notes
A.4.7.1 (id, kind ∈ {rationale, memory, decision}, about, owner, text, confidence?, chose/over?); about is the only link; no because.
A.4.7.2 The checker resolves about, enforces requires note, prints notes, derives nothing from text.
A.4.7.3 Memories' checkable parts become claims (Bend-E5: 34 of 36).

A.5 EVIDENCE
A.5.1 Records
A.5.1.1 r = (id, kind, result, claim?, code, deps, harness, provider?, scope?, bound?, assumptions, facts?, judge?, identity?, about?, revision, time, signers); id = H(JCS(statement)); envelopes of one statement are one record (all evaluated, signers unioned); provider = (qualified name, version as data); self-signed judgments have none.
A.5.1.2 Kinds: observation (contradicts; supplies coverage); test (tested); proof (proven; persisted iff persist); judgment (judged axis; claim judgment or answer; answers audit-only when persisted); equivalence (≡, ⊒).
A.5.1.3 declared < tested < proven; s(r) = level(kind) if the provider is base-declared, else declared, and a record of a provider the base does not declare only contradicts: it never establishes and holds no reason under A.5.4 [D9]. No strength field.
A.5.1.4 Manifests are inputs (several schemes per (x, π) allowed); no carry provider.

A.5.2 Providers
A.5.2.1 Presence: reported facts and counterexamples are true at their stated location (nearest enclosing identity; callees resolved). Absence: on complete entries every true fact on declared channels is reported. An effect performed through a root the entry supplies as a value (a callable, a client, resource code) is reported at the supplying entry, or that entry is incomplete; a receiver that only calls a supplied value with a structural type is not required to report it [D21]. Presence-sound observers report n on every effect fact (RJ14).
A.5.2.2 complete counts only for providers absence-sound under G* in the use's direction: (a) refutation, (b) coverage.
A.5.2.3 Channels effect(p) (p matches t iff tag and kind equal and value * or canonical), call(L), edge(k), edge(k, p); no hatch channel.
A.5.2.4 Decides: template Q, statements L, equivalence.
A.5.2.5 complete: false is mandatory for unparsable files, unresolved callees (including calls through injected objects or interface members the provider cannot resolve to an implementation) [D21], dynamic SQL and unexpanded macros.
A.5.2.6 implementation (path globs, identities, or a digest: runner, configuration, lockfiles, toolchain pins) is required for observation, test and proof providers (E-provider); no implicit configuration identities. Identities give sub-file granularity: pkgjson("package.json#scripts.test"), gha("….yml#jobs.<job>") [D9].
A.5.2.7 harness: identities beyond code and deps that defined the check (tests, local imports, fixtures, proof harnesses, scanner config); required (RJ14).
A.5.2.8 deps complete: complete deps and harness from module graphs or traces; proof deps transitively closed (callee contracts, broadcast lemmas, axioms); proofs list verifier-trusted items after macro expansion as hatch assumptions. Reuse is CI caching through deps.
A.5.2.9 persist; trusts tool(name, version).
A.5.2.10 produces judgment = the review relay (no bridge flag).
A.5.2.11 A base-declared identity makes a provider authenticated: records MUST be signed by it (RJ07); identities SHOULD be default-branch workflows; head providers MUST NOT share one (E-provider); base sharers count as unauthenticated. Unauthenticated providers keep force and are listed in health ("CI assembled these records and the change could not alter them"). Where the gate runs is open question 9.
A.5.2.12 Signing separation: authenticated providers sign, from a job executing no head code, the digest of the output they received, in workflows where no head-executing job holds id-token permission. Observers, relays and the manifest provider never execute head code. Test, proof and equivalence providers do by nature and are listed as executesHead ("the code under test cannot alter its reported result"), tested by teeth.
A.5.2.13 E-provider-missing (step 4b, blocking), per decided claim: an authenticated base observer supplies no authenticated head record; or an authenticated base test or proof provider supplies, for a head claim it decides, no authenticated applicable record at head or reusable through deps complete. Producer-changed and inconclusive records count as supplied; rejected records (A.12.6) do not. A manifest not signed by a base manifest identity is E-provider-missing as well (A.5.2.17).
A.5.2.14 Calibration: Bend-C3 effects 65.6% and Bend-C4 calls 43.5% precision (heuristic); manifest markers exact; Verus proofs presence-sound for success, failures inconclusive. Test providers MUST report a deterministic assertion failure as contradicts with a counterexample {seed, inputs, assertion} and keep inconclusive for crashes and timeouts [D21].
A.5.2.15 rerun is offered iff the provider produces observations, tests or non-persisted proofs; no ci, strength or versions fields.
A.5.2.16 Lean proof providers map #print axioms: propext, Quot.sound and Classical.choice to the tool assumption lean@<version>; sorryAx and the compiler's implementation axioms to hatch assumptions at the cone identities; a user axiom a to a hatch assumption <id>/axiom, or to a named assumption when a base boundary assumes it. Bend and Lean hatch markers come from registry entries (A.12.2.8), never from records.
A.5.2.17 Manifest identity [D27]: when the base shape declares manifest <identity>, both manifests MUST be DSSE-signed by it from a job that executes no head code (A.5.2.12); a missing, unsigned or wrongly signed manifest is E-provider-missing (subject manifest), never invalid. Without one, health lists both manifests as unauthenticated with the assumption "the gate built both manifests in a job that executed no head code". A head edit of the field is an L7 question acting after merge. The checker still rebuilds the tree from each manifest, so only digests, refs, markers and flags rest on the identity; T2 and the H5 guarantees hold over authenticated manifests.

A.5.3 Requirement, satisfaction, applicability
A.5.3.1 R(c) = (level, judged, pins, projection): level* = max(written or template level, floor(tier*(c))); judged iff or judged (only where judges are listed, else E-policy); pins from by; projection unit (default), contract or trust. Informal laws and surface reviews: (none, true, pins, projection).
A.5.3.2 E-route, laws only: level* declared; or a head-declared provider deciding it produces a kind of level ≥ level*; or judged with judges. A declared floor marks declared-only laws.
A.5.3.3 R_h ≥ R_b iff level_h ≥ level_b (none highest), judged_h ⇒ judged_b, pins_b ⊆ pins_h, projection_h = unit or equal; strictest = tuple maximum (judged only if all; pins united; unit unless all agree).
A.5.3.4 Req(c, kind) from c and M_h; cited identities of K at π = x ∈ code(K) with an entry at π whose parent is a file or uncited at π; marked = own has a hatch marker. on unit u: (bind(u), unit) for tests and proofs; for judgments (bind(u), π) plus (y, π) for every function y ∈ code(comp(u)) reachable from bind(u) through Refs° (free names, this and super methods, module object members; A.12.2.10) (data it references is already in its digest) [D4]; (bind(u), unit) at trust if it or a descendant is marked. on component K: cited identities at unit plus (f, own) per file of code(K) (judgments at π, files only for unit); at trust (x, unit) per marked non-file and (f, own) per marked file. on code x: (x, unit) or (x, file). Hosted statements add (ref, closure). An identity without projection π (raw and file identities) is cited at file [D4]. trust is a selector, not a projection. DocumentedBy's Doc parameter makes doc edits stale its judgment.
A.5.3.5 r applies to c iff supports with r.claim ⊒ c (contradicts with c ⊒ r.claim), r.code ∪ r.deps ⊇ Req(c, kind(r)) (judgments: r.code), and a judgment's judge is eligible for c (per claim). Empty citations: RJ10; partial ones give stale.
A.5.3.6 An observation entry for x serves c iff x ∈ F(c) and a declared channel of T(c) applies to x.
A.5.3.7 Sat(c) iff Req(c) = ∅ (vacuous: listed in health and teeth) [D14], or no open sound contradiction and (level* declared; or a usable applicable test or proof with result supports and s(r) ≥ level*, respecting pins; or judged(c) and a usable applicable judgment with result supports, respecting pins, from two distinct eligible persons when tier*(c) is final). Only supporting records establish: a contradicting record, whatever its force, never makes c Sat, and a heuristic contradiction neither establishes c nor prevents Sat. So a failing test from a provider without presence soundness leaves the law unestablished (vector A.11.2.4).
A.5.4 Usability
A.5.4.1 Reasons, first match: stale (cited, deps or harness digest ≢ M_h, identity gone, revision-tied record not at head unless reused through deps complete, claim no longer ⊒, or Req partly uncited; judgments reuse by citation; a head-revision record citing a digest that contradicts M_h is rejected by RJ13 instead, so stale arises for records at other revisions or reused through deps; a moved harness digest is stale) [D9]; expired (judgment older than max_age(tier*(c)), judgments only); assumption (undeclared assumption); weak (level below level*, or pinned out); producer-changed (implementation, base ∪ head, or harness meets Δcode ∪ deleted, and the record is otherwise usable and either supports or contradicts with force; never for inconclusive records, which hold no reason) [D9]. An exact stale_iff (stale iff a fingerprint, revision included, changed) holds only when no earlier reason applies.
A.5.4.2 Stale, expired: no force. Producer-changed, assumption: contradiction force only; such observations give no coverage. Observation entries are usable at head, or with deps complete and digests and deps ≡ M_h.
A.5.4.3 Law reason (c not Sat, no open sound contradiction): the first of (assumption, weak, producer-changed, expired, stale) held by some record for c, meaning a supporting or contradicting record of a base-declared provider (or a judgment) whose claim relates to c by ⊒ in its direction (A.5.3.5) and that is applicable or omits part of Req (stale); missing if no such record holds a reason, including when there is none and when the only ones are usable heuristic contradictions, inconclusive records or head-only providers' records. The reason is therefore total, and producer-changed never masks assumption or weak [D9].
A.5.4.4 Assumptions of a test or proof: declared ones plus M_h hatch facts in cone(r) = closure of code ∪ deps under Calls° ∪ Refs° and same-provider, same-revision proof records (two-level admit vector). Declared iff: hatch allowed by its identity's boundary in base (under ρ) and head; named assumption in assumes of a base boundary meeting Req or cone; tool in the base trusts. Exceptions never declare assumptions. A final law is never satisfied through any hatch fact in its cone (any h ⇒ Hatch, allowed or not) [D11] or any named assumption; only tools in the base provider's trusts are assumed. Dischargers: remove, then declare.
A.5.4.5 Macros outside the registry's builtin list, in any position, make identities not hatch-complete, and the manifest flags them so (A.3.4.4, A.12.2.8; open questions 10 and 20).
A.5.4.6 A producer-changed answer accepts the producer change only: c is re-evaluated with the answered provider's records treated as not producer-changed, and any reason that remains (assumption, weak, expired, stale, missing) keeps an obligation open with that reason [D9]. On a final law it needs two persons (A.6.3.4).
A.5.5 Force
A.5.5.1 Fixed: violating observed facts are sound contradictions if presence-sound under (a), else heuristic; complete absence-sound entries refute lower bounds; tests and proofs establish at their level and, with a counterexample, contradict (sound if presence under (a)), without one are inconclusive; eligible judgments establish (judged) or contradict soundly; eligible answers discharge (only obligations with an answer discharger, A.7.6.5) or are exception answers; contributing equivalences give ≡ or ⊒, others are hints.
A.5.5.2 bound feeds teeth only. A fresh contradicting judgment beats supporting ones; no latest-wins; mistaken judgments clear when citations move or an exception carries them.

A.5.6 Equivalence and ⊒
A.5.6.1 Contributing equivalence: provider base-declared, presence-sound, deciding equivalence under (b); in claim space also deciding both claims and citing both Reqs (and closures) while ≡ M_h. equivalent asserts both directions; one direction is implies (E3: 14/14).
A.5.6.2 Code ≡: union-find over contributing equivalent records and multi-scheme digests; classes named by least digest.
A.5.6.3 Claim ⊒: reflexive-transitive closure of equal NF under ρ, contributing equivalent and implies records, and the op order (selectors over head nodes under ρ). ≡ only from two-way records and multi-scheme manifests.
A.5.6.4 Op order: effects.upper same unit, cl(C_h) ⊆ cl(C_b); path.forbid S, T, K ⊇, V ⊆; edge.forbid same kind, S, T ⊇, X, Y ⊆; cycle.forbid K ⊇; schema laws equal schema, schemaFp, on, args by the base order table; hosted laws equal NF and the statement ref's closure digests ≡ between M_b and M_h, or a contributing code-space implies record [D13]. Effect forbids and authority: none.
A.5.6.5 Uses: freshness (≡), applicability (supports flow stronger to weaker, contradicts the reverse), heirs, L3–L4, L6.
A.5.7 Fingerprints
A.5.7.1 fp(c) = H({"v":"shape.claim.v1", op, args}) after resolution, expansion and elaboration (A.12.8.1). Statements: {schema, schemaFp, args}; {ref, projection: "closure"} (no digest; closure moves seen by freshness and L4); {text}. Names, owner, tier, requirement, bindings, locations, comments and order excluded; final and family not in the NF.
A.5.7.2 Code digest SHA-256(σ ‖ LF ‖ canon_σ(π(x))), σ = <lang>.<projection>.v<n>: parse with the pinned parser; canonical printing; drop only inert comments (A.12.2.9; markers and pragmas kept); literals by value; the unit projection (and the Verus projections, by their schemes) appends env(x) (tree-only resolutions; functions by identity, data by canonical initialiser, transitively), file and own never do (A.3.2.5), and the manifest records env(x)'s identities as refs. File digests are formatting-insensitive too [D8]. Non-file TS, Rust, Verus schemes are v2; H7 measures env's cost. VIR schemes absorb syntax migrations (E1 44/44); equivalence records carry API migrations (E3 42/44).
A.5.8 Authentication and persistence
A.5.8.1 Judgments are signed by the judge or relayed by a base-declared relay naming the judge's code-host identity (RJ07, RJ08); judge and reject lines passed as reviews without a relay are not judgments (A.7.6.8) [D28].
A.5.8.2 Persisted: exactly shape/evidence/<2 hex>/<64 hex>.json holding the record with that id (else E-evidence-path); only judgments and signed persist proofs with deps (RJ11); answers audit-only; append-only per file (E-evidence-rewrite); re-evaluated every run.
A.5.8.3 Signatures: ed25519 keys (no verified time; base identities) or Sigstore bundles verified at the Rekor integrated time with trustRoots keys, never the wall clock.

A.5.9 Monotonicity
A.5.9.1 T6: removing a record unblocks only if it is an observation, a contributing equivalence, a contradict-force record, or an unauthenticated producer-changed test or proof; for authenticated providers E-provider-missing turns such removals into errors.
A.5.9.2 T6′: adding a head-revision record lowers severity only by establishing, discharging or covering; adding a base-revision record lowers it only by showing an obligation preexisting (A.7.3).
A.5.9.3 Unblocking categories: contradict-force records, equivalences that force depends on, call facts behind footprints, unauthenticated producer-changed records.

A.6 CHANGE AND GOVERNANCE
A.6.1 Change
A.6.1.1 Δ = (S_b, S_h, M_b, M_h, records, baseRecords, persisted, reviews, authors, change, now); edits in place are changes.
A.6.1.2 Head = landing revision; base = first parent (merge-base for a branch tip); commits verified against revisions and manifest trees (else invalid).
A.6.1.3 now* = max(now, base committer time) (clockClamped); RJ06 re-applies to persisted records each run; keys and bindings never use now.
A.6.1.4 ρ: same name and kind; was Old (components, resources, units, claims, actors); identical non-empty bindings over M_h; conflicts unmapped (health); rule 3 (unique remove-and-add per kind and module) is a hint only, and the diagnostic of an undecided part suggests the was line [D17]. E-was: was X while X survives, or X named twice.
A.6.1.5 Δcode = {(x, π) : x new, or digest_π(x) moved under a common scheme}; a set of cited pairs meets Δcode iff they share a pair [D8]. deleted = ids(M_b) ∖ ids(M_h). A new x is relocated from a deleted y iff kind and language agree, own_b(y) = own_h(x), and no other new or deleted identity of that kind has that own digest [D6]. Finest changes: identities whose own digest moved and new identities that are not relocated. Vector: a directory move of unedited files keeps every own digest, relocates every identity and yields no finest change and no new hatch fact (anvil a27a5959 raised 291 contradictions under version 6).
A.6.1.6 Modes change (base possibly empty), audit (no base: G* reads the head as governance base; nothing introduced, every obligation preexisting under rule 6, no loosening or coverage) [D16], preview (A.12.7.2); 0.x bases via migrate; gates accept change only.
A.6.2 Governance (G*)
A.6.2.1 H(c_b) = {c_h ⊒ ρc_b}; effect forbids and authority: equal NF only.
A.6.2.2 H_A(c_b): when L3 is implied by G_A or a finished search and H(c_b) = ∅, the head structural upper bounds rejecting some candidate edge on ρc_b's support pass over W_decl(head) ∪ all type-correct edges.
A.6.2.3 tier*(o): for a contradiction of an effect forbid, summary or authority at fact (x, b), max(tier_h(c), Lvl_b(att_b(x))(b)), with Lvl_b computed by A.4.4.7 under the base shape over M_h; for every other obligation, max(tier_h(c), tier_b(c_b) for c ∈ H(c_b) ∪ H_A(c_b)). A base claim whose final loosening was answered by two persons in this run contributes tier_h of its heir instead [D11]. The witness condition of version 6 is dropped: it was implemented by neither checker (DRT) and the replacement is upward-conservative. R*(o) likewise (strictest).
A.6.2.4 tier*(K) = max(tier_b(ρ⁻¹K), tier_h(K)), ungoverned normal; tier*(c,x) = max(tier_h(c), tier_b(c_b) for c an heir of c_b with x ∈ F(ρc_b)).
A.6.2.5 owner*(c_h) = base owners of what it inherits, else its head owner with base memberships; one eligible actor per member; head-only owners never approve.
A.6.2.6 policy*: blocks united, least max_age, highest floor, judges intersected, least budget; the self fallback (A.6.3.3) reads the base judges alone [D12]. Actors, identities, memberships, operators: base. Providers (validated against base declarations): (a) contradiction and refutation force: presence and absence each base ∨ head; (b) establishing force, meeting coverage, deps complete, ≡/⊒: soundness base ∧ head, channels and decides intersected; (c) producer change: implementations united; (d) identity, produces, persist: base; (e) observability for coverage need, exploitation and the declared-only listing: base declarations alone [D3]. Head-only providers act under (a) only (level declared, no reason, "establishes after merge"). The manifest identity: base (A.5.2.17).
A.6.2.7 L1 and L4 use each shape's own effect order, hatch kinds and template bodies; L1's verb universe is the union.
A.6.2.8 Head governance edits are L7 questions and act in the run only where they cannot lower severity (T2′).

A.6.3 Authors and eligibility
A.6.3.1 authors (CI, platform data): opener, pushers, commit authors, committers, Co-authored-by trailers, agent-session principals, marked verified and bot; evidence-only commits excluded with their people.
A.6.3.2 authors* = base actors of author identities closed under agent → operator, team operator → persons, person → operated agents; verified* likewise over verified identities; trailers only exclude. Roles exist only by naming (owner, judge, author); no approver role.
A.6.3.3 j eligible for o iff: a base actor acting through an authenticated record, or through an approve line CI supplied in this run (answers only, A.7.6.8; listed unauthenticated); listed by tier*(o)'s judges (owner = the item's owner resolved to persons: owner* per claim, base owner per vocabulary item, base shape owner for policy, providers, actors, vocabulary coverage and shape; a team named in judges contributes its persons, its agents only when agents is also listed; agents = every agent; final ignores agents); never an agent for loosenings, exception answers, producer-changed answers or any act on a final claim; and j ∉ authors* for acts of this change (answers, and judgments whose about.change is this change or that the relay produced in this run; persisted judgments of earlier changes keep their eligibility), or the self fallback: j is a person, o involves no final item, j is the only base person eligible by role under the base judges ignoring authorship, no author is an unmapped bot. Self answers are marked (with exploited) and counted.
A.6.3.4 Final: two distinct eligible persons, one of the item's base owner and one of the base shape owner (two persons of that actor when they coincide), no agent, no fallback, for final loosenings, claim judgments establishing or contradicting a final law, producer-changed answers and heuristic dismissals on final claims [D11]. Coverage with an unmet final pair: two distinct eligible persons, no agent, no fallback, who together cover the owner* of each claim with an unmet final pair, K's base owner and the base shape owner [D11]; vector: claim owner = K's owner = a one-person team (bob) needs bob and a person of the shape owner. E-policy rejects final items lacking two distinct persons; a change whose authors exhaust them cannot pass, by design.
A.6.3.5 The fallback fits Shape (one maintainer plus an agent) and cannot be enabled by stacking on a colleague's commit (repro.py B7).

A.6.4 Base totality
A.6.4.1 Shape errors apply to the head only; the base never makes the verdict invalid.
A.6.4.2 The base elaborates leniently (failures: empty bindings, baseDefects; bad pins drop the pack).
A.6.4.3 Base bindings over M_h: default names take the unique M_h match; else x_b if present; else new identities in x_b's file (rename in place); else ∅; globs match what they match.
A.6.4.4 Tied base globs and base unit overlaps: strictest view (Perm intersected, Lvl max, Con united) [D22].
A.6.4.5 Unparsable base or failed migrate: L0 undecided (subject shape, base shape owner), L1–L7 and coverage skipped, blocking until answered.
A.6.4.6 Vectors: deleted bound file and unit give a defined verdict; f renamed to g in place with the unit rebound to h gives L6 loosened at g.

A.7 OBLIGATIONS
A.7.1 Shape and kinds
A.7.1.1 Fields: key, kind, reason, questions, claim, subject, witness or counterexample, force, introduced, severity, tier, budget, owner, assignee, group, dischargers, causes, binding, exception, exploited, final; no approvers field.
A.7.1.2 causes {type, id, text}, proximate to root; types fact, record, code, binding, claim, template, pack, base-claim, provider, policy, exception, note, assumption.
A.7.1.3 Dischargers per kind: contradiction (sound: edit code; exception plus exception answer, non-final; edit shape; heuristic adds a dismissing answer bound to support code, two persons if final). loosening (revert; was; implies record for undecided L4; answers by the subject tier's judges bound to the base owner, persons only, plus the base shape owner if final). unestablished (missing, weak, stale: rerun or provide, else shape judge; expired: judge; producer-changed: a person's answer, two if final; assumption: remove, else declare; last: exception, lower the requirement; only producer-changed has an answer discharger). coverage (answer by K's base owner and each unmet claim's owner*; when a pair is final, two distinct persons covering them and the base shape owner, no agent, A.6.3.4; bind or declare; add an observer, effective after merge).

A.7.1.5 At most one of a sound contradiction and unestablished per claim; only sound contradictions suppress unestablished.

A.7.2 Keys, bindings, groups
A.7.2.1 Keys depend only on kind, claim fp and subject.
A.7.2.2 binding = H({key, affected, code, delta}): affected = support code (laws: Req identities), Req identities (plus implementation and harness finest changes when producer-changed), uncovered identities, vocabulary sites, or a loosening's affected positions and cells; code = [id, projection, base|null, head|null] under the base scheme: every Req pair for unestablished and law contradictions, else (x, own) per affected finest change plus (d, own) per changed dependency that put x in the coverage set; delta = question-prefixed loosening delta, or for coverage "<claim fp> <channel>" per unmet pair [D22]. No revision: unrelated rebases keep answers; moved code, binding edits and widenings reopen. Coverage binds unit or own digests only.
A.7.2.3 Groups: connected components of obligations sharing a support fact (A.4.4.11; loosening parts: realising facts), an affected finest change, or a cause: a changed implementation or harness identity of the provider behind a producer change, or a removed or changed base item named in their causes [D10]. g: + hex(SHA-256(JCS(sorted keys))); computed before answers; display and budget only; tier = highest member's; carry no answers.
A.7.3 Introduced
A.7.3.1 New facts: an observed fact at x is new iff x ∈ Δcode (any projection) or its anchor's deps changed, and no usable base-revision entry reports it, at x or at the identity x is relocated from (A.6.1.5), with n_b ≥ n_h, both present (a missing n counts as unknown, hence new) [D15, D6]. A.7.3.3 Introduced iff: a loosening or (vocabulary) coverage obligation; a contradiction of an effect forbid, summary or authority whose witness holds a new fact; a structure contradiction whose witness needs a new lifted edge [D5]; a refutation one of whose footprint identities is in Δcode or whose missing fact a usable base-revision record reported [D7]; a law obligation whose Req, or the cone (A.5.4.4) of a record that contradicts the claim or holds the obligation's reason (A.5.4.3), meets Δcode ∪ deleted [D4], except a law contradiction that a usable base-revision record of the same base-declared provider already made with an equal counterexample (equal assertion and inputs; for a judgment, the same record) [D4]; or an obligation whose reason is producer-changed. Claims, bindings, exceptions and provider additions never introduce by themselves. Laws contradicted at base are listed in health with their counterexamples. Vectors: SCC merge; second site; new call along an existing lifted edge; callee bug (through the contradicting record's cone); callee edit staling a deps-complete test record (through the reason-holding record's cone); base-failing law with a different counterexample (introduced) and with an equal one (preexisting).

Unmapped resource code is handled by vocabulary coverage.
A.7.4.5 Code under no constraining claim is covered vacuously.
A.7.4.6 Vocabulary coverage: per unmapped canonical t of a bound tag.kind, or undeclared verb V, named by a new fact at x under a claim with an applicable channel: one obligation (subject resourceCode t or verb V; shape owner; highest tier*(c,x); data the sites); bind or declare, else answer; non-new facts go to health unmapped.

A.7.5 Severity
A.7.5.1 First match: 1 errors; 2 an introduced sound contradiction with tier*(o) final blocks; 3 L0 blocks until the base shape owner answers; 4 final loosening, and coverage with an unmet final pair, block until two eligible persons answer as A.6.3.4 requires; 5 matched: owed debt if not introduced or exception-answered; 6 non-introduced: owed (preexisting; in audit mode every obligation); 7 sound contradiction blocks, heuristic owed; 8 exploited loosening blocks, producer-changed with Req meeting Δcode ∪ deleted blocks; 9 policy*: unestablished, coverage, latent loosening block iff listed. A.7.5.4 Audit introduces nothing; old drift never blocks unrelated changes (R4: 83–98% of commits in 5 of 8 repositories carry an outstanding assume or admit); first adoption is owed.

A.7.6.5 An approves answer whose about.change ∈ change.ids discharges an obligation m that one of its refs expands to only if (1) m has an answer discharger (A.7.1.3): a loosening (L0 included), a heuristic contradiction, an unestablished obligation with reason producer-changed, a coverage or a vocabulary coverage obligation; and (2) for each answer item of m some answer naming m is from an actor eligible for that item (A.6.3.3-4). Items: a loosening's subject (two persons if final); the claim, for a heuristic contradiction or producer-changed obligation (two persons if final); K and each claim with an unmet pair, for coverage (two distinct persons covering them and the base shape owner when a pair is final, A.6.3.4); the shape, for vocabulary coverage. A producer-changed answer then re-evaluates the law by A.5.4.6. A ref to any other obligation (a sound contradiction; unestablished with reason missing, weak, stale, expired or assumption) discharges nothing; it acts only as an exception answer if A.7.6.6 holds. So no answer meets an evidence floor or a route (E-route), declares an assumption (EM-4; exceptions never declare one either, A.5.4.4) or waives a sound contradiction (Invariant 2, T3). A heuristic dismissal discharges only its key.
A.7.6.6 Exception answer: m matched and introduced, with an eligible non-agent for each excluding claim's owner*; m becomes debt.
A.7.6.7 Sound contradictions and unestablished obligations with reasons other than producer-changed have no answer discharger; they leave only by evidence, a claim judgment (shape judge), a code or shape edit, or, when matched, an exception answer making them debt. answered records as ∈ {discharge, exception-answer}; obligation.exception is set only when the exception has taken effect (debt).
A.7.6.8 Without a relay, CI-computed reviews act only as answers: approve lines discharge or exception-answer in this run, their authors eligible as if authenticated (A.6.3.3) and listed unauthenticated in health. shape judge and shape reject lines then make no claim judgment and are counted in health as unrecorded: a claim judgment is evidence and persists as a record, relayed or signed by its judge (invariant 5) [D28]. Without a relay, judges commit self-signed judgment records under shape/evidence/ (A.5.8).
A.7.6.9 One answer may list many obligations, each checked separately.

A.7.7 Debt
A.7.7.1 Debt: rule-5 obligations. Each debt row lists every matching exception (sorted by id) and takes exception, owner (that exception's owner, A.15.7) and expiresInDays = ceil((expires − now*)/86400) from the earliest-expiring one (ties: least id), flagged at ≤ 14. When that one expires the obligation leaves debt, even if later-expiring exceptions still match its other excluding claims, since each excluding claim must be matched (A.4.6.5) [D22]. Vector: two exceptions on one obligation's two excluding claims, 30 and 311 days left: the row shows the 30-day one, and debt ends when it expires.
A.7.7.2 Preexisting: open non-introduced obligations, owned, never blocking; preexisting sound contradictions of final claims are listed in health as final drift.

A.12.1.1 Digests sha256:<64 hex>; bare hex in in-toto digest maps.
A.12.1.2 Code identity <lang>:<path>[#<symbol>]: repository-relative POSIX NFC, % and # percent-encoded; symbol segments joined by . (TS) or :: (Rust, Verus), each encoding %, # and . (TS private #x of C is C.%23x). ts("src/a.ts#f") in shapes = ts:src/a.ts#f in records; diagnostics use the shape spelling.
A.12.1.3 Cells cell: + JCS [v_b, v_h] of Q.*, ungoverned, or (base) sorted lists of tied pseudo-units.
A.12.1.4 Resource code <tag>.<kind>("<canonical value>"), * in channels.
A.12.1.5 Record id: H(JCS(statement)) (DSSE payload when enveloped).
A.12.1.6 Refs: bd: + ≥16 hex of a binding; claims by id or c: + ≥16 hex of fp.
A.12.1.7 Subjects: shape:claim/<id> (fp), shape:code/<identity>@<projection> (digest, shape.scheme), shape:scope/<provider>/<revision> (scope root), shape:manifest/<revision> (manifest root), shape:answer/<change> (H(about)).

A.12.2.9 Inert TS comments: not /** */ or ///, no @ or #__, none of eslint istanbul c8 prettier biome webpack vite jsx; JSDoc is never inert, by design (it can carry types). A first-line hashbang is never inert; in 100755 files no comment is. The scanner re-scans template literals [D8].
A.12.2.10 TS resolver (tree only): relative specifiers probed exact, then TS extensions, then /index; workspace package names through string exports["."]; nearest tsconfig paths/baseUrl with in-tree extends; else bare. Re-exports followed (ambiguous export *: (specifier, name)); functions by identity, data by canonical initialiser, transitively, cycles cut. Inside a class, this.m and super.m resolve to method m of the enclosing class or its in-tree superclass chain (static; subclass overrides are not followed), and o.m for a const-bound object literal o of the module resolves to its member m; both enter env(x) by identity and refs [D4]. No implicit configuration identities.
